# NGN 0.3.0 release preparation — 2026-10-07

Candidate for CCRL: the claimed H512 engine with the network embedded and
UseNNUE on by default, plus one audited correctness fix. All execution on WSL.

## Final audit (read-only, three agents)

- **Provenance:** no copied third-party code or tables in the binary
  (`main`, `engine`, `internal/sliderray`, stdlib only). Docs/identity were
  stale (0.2.0 text, WDL25 grant, `id author ngn team`); updated for 0.3.0.
  Training-data chain (sfbinpack decode, Bullet-layout packing, 64-knot score
  map fitted to SF18 evaluations) now disclosed in `LICENSES/TRAINING-DATA.txt`.
- **UCI/time:** CRLF, setoption parsing, bestmove-once and legality, mate
  output and SMP stop/join correct. GUIs that echo `EvalFile <empty>` would have
  silently selected HCE; the embedded default now survives empty, `<empty>`,
  `<embedded>` and unloadable paths. GOMAXPROCS follows Threads again (the claim
  ran with GOMAXPROCS=1), unless GOMAXPROCS is set in the environment.
  movestogo 1 lets one move use the bank minus 200 ms (emergency + overhead);
  time management is unchanged here because TC changes need real-clock games.
- **Search/NNUE/SMP:** NNUE loader, incremental updates, arithmetic bounds,
  AVX2 assembly and per-thread state correct; helpers use NNUE. One bug:
  the per-move clock check in `alphaBetaPV` broke out of the move loop and then
  stored the partial result in the TT (as UpperBound/Exact at full depth) and
  correction history. Every other stop site returns `stoppedSearchScore`.

## Changes

1. Embedded network `engine/nets/ngn-h512-c6c12796.nnue`; default build profile
   `nnue` (`-X main.releaseProfile=hce` keeps the locked HCE); version
   `0.3.0`; author Bryan Ehrlich; docs/notices.
2. Move-loop clock stop returns `stoppedSearchScore`.
   Regression test `TestStoppedSearchNeverStoresRootTTAtAnyCheckSite` sweeps
   every clock-check site of a depth-2 search.
