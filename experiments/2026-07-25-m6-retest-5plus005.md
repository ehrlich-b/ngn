## Predeclared PASS rule — (b)/(c)/(d) unchanged, (a) made QUANTITATIVE

PASS requires **all four**. (b), (c), (d) are carried over verbatim from the 2026-07-03 manifest; only (a)
changes, and only to replace a subjective word with a number.

- **(a) No bias — QUANTITATIVE:** at the 8000g cap, **|penta point estimate| <= 5.0 AND the 95% CI contains 0
  AND the CI half-width <= 8.0**. A decisive H1 in either direction is still an outright FAIL. Rationale: an
  A/A is 0 by construction (same binary, paired openings, colors swapped), so any surviving systematic offset
  indicates the TC interacts with scheduling or the clock; the tolerance is deliberately tight.
- **(b) Clean clocks — STILL THE HEADLINE, STILL HARD-FAIL:** flag-outs new 0 / base 0. **ANY flag-out on
  either side = FAIL.** Note this already passed at 1600g; 8000g is a 5x stronger test of it, and that is a
  real part of the value here — the halved clock at c8 is exactly where the time manager would first crack.
- **(c) Adjudication fires:** "Adjudicated early: N decisive, M draw" with N > 0 AND M > 0.
- **(d) Throughput:** measured g/hr reported; expect ~1900-1950 (~2x the 961 baseline).

**On PASS:** 5+0.05 c8 is enabled for **Stage-1 filters and SPSA batches only**. Per-change verdicts stay at
10+0.1 pending M6b (sign-agreement on 2-3 changes run at both TCs). Record the new baseline g/hr.

**On FAIL via (a) with a tight CI:** 5+0.05 c8 is rejected *for good* — a real, measured TC asymmetry, not a
