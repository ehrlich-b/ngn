# NNUE self-play with independent HCE labels

`cmd/nnuegames` plays both sides with a specified NGN-v1 network and searches each sampled position separately with HCE for its label. The HCE budget must be at least 4,000 nodes. Games use random eight-ply openings, a 200-ply cap, and the usual side-to-move outcome. Game IDs skip multiples of 50 so that no new positions enter the existing holdout. Games aborted by an incomplete search or the time limit are discarded. The output is an exclusively created gzip stream; treat it as complete only after a successful exit and gzip validation.

`train_nnue_stage3.py prepare` decodes one shard at a time to bounded tensors. `--start` appends numbered tensors without overwriting existing files. Prepare the original shards first, then prepare new shards using the original shard count as the start index. `train_nnue_stage4.py` streams one shard at a time, uses 128 hidden units, Adam at 0.0005 and cosine decay, and validates exclusively on the original shard holdout. `--original` is the original shard count and `--total` is the total count. Export the completed raw checkpoint with `nnuebridge convert -format bullet-raw` and validate the exported model before using it.
