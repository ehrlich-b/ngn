## THE METHOD — GM-climb operating system (replaces the old single-SPRT loop)
**Era pricing:** a keep is worth median +4-8 self-play (good case +10-35; only bugfixes are ever 3-digit). Never price an item as a block; no elo number on a theory until its gate passes.

**Three-tier gating:**
- **Tier 1 — per change (the FILTER, not the truth):** probe (deterministic, free) → tactical 30/30 → `sprt 10+0.1 [−5,0]` to 400g cap → sign + KEEP rule. Job: catch regressions ≥~25 and give a sign. The median real item is invisible here — bank it under the KEEP rule anyway; Tier 2 owns the truth.
- **Tier 2 — per batch (the VERDICT):** every **4-6 keeps**, SPRT the BUNDLE vs the pre-batch anchor at **≥2,000 games** + tactical + `make acpl` if eval touched. Pass (positive central) → anchor advances, keeps become permanent. Fail (negative central) → bisect halves serially until the offender drops. This is the solo-machine substitute for farm resolution — **mandatory, starting with the current batch**.
- **Tier 3 — era:** real-clock `gauntlet -tc 120+1` vs Blunder every ~2-3 batches; multi-family pin only when a number is wanted.
- **Volume (DONE 2026-06-11):** concurrency null-test PASSED at conc 3 (0 flags/200g, exact 3.0× throughput, +31 within the n=200 null band — no bias mechanism absent starvation). **Adopted: Tier-1 1200g, Tier-2 3-4k, conc 3, same wall-clock (±30→±17).** Tripwire: SUSTAINED/one-sided flag-outs → conc 2 (a symmetric transient pair is benign — W1 G100-101, one each side, net wash, 447 clean after). Short-TC stays the gate (the directive is the TC, not the concurrency). The cert criterion that matters is the flag-out count (the failure mechanism), not a noise-band on the score.

**The income portfolio (interleave all four; the class income statement says so):**
1. **Search grind** — W/O/S items below, the staple.
2. **Eval shapes → tune RUNS** — expose a frozen shape, bank the conversion, then a **full Texel re-tune of the expanded basis as its own queue item** (tune runs = 11-16% of class banked elo; the only non-bug ≥+50 in 672 commits was a tune run).
3. **Simplifications** — 1-in-4-keeps class pattern; removals at [−5,0]. First candidates: recapture extension (CG has none; also A9), IID after W6 lands, dead eval code (below).
4. **Bug channel — the only 3-digit source.** Live candidates: **D2 plies-vs-moves time bug (Weiss's +499.7 twin)**, S1 qsearch cap-6 truncation, recapture-ext firehose (14-19K/400K). Keep zzbias/lossxray hot; every weird measurement gets one bug-hypothesis pass before a feature-hypothesis pass.

**Standing disciplines (non-negotiable):** KEEP rule (improvement OR correctness + no measured regression ⇒ KEEP; REJECT needs a concrete regression) · `make acpl` before SPRT-ing eval changes · never verdict a mid-run/killed SPRT (G68 lesson ×2) · probe = filter, SPRT = verdict (4 confirmations) · node-identity re-lock after keeps · one SPRT lane at a time, no other compute while a real-clock run is live · never P-cores · single-sentence local commits · closed-lanes ledger before reopening anything.
